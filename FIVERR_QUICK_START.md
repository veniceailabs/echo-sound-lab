## 💰 Week 2: Your First Orders

### Processing Each Order (1 hour per order)

**Mixing Order:**
1. Download vocal + beat from client's message
2. Open Echo Sound Lab at https://echo-sound-lab.vercel.app
3. Go to `/studio/mixing`
4. Upload beat as track 1
5. Upload vocal as track 2
6. Apply professional mixing:
   - EQ each channel (reduce harshness, boost clarity)
   - Add compression (moderate attack, fast release)
   - Add reverb/delay to taste
   - Balance levels
7. Export mixed vocal (Download button)
8. Save as `[ClientName]_Vocal_Mixed.wav` and `.mp3`
9. Upload to Google Drive
10. Share download link with client
11. Mark as delivered

**Mastering Order:**
1. Download stereo mix from client
2. Open Echo Sound Lab
3. Go to `/studio/mastering`
4. Upload mix
5. Select genre (client specified)
6. Select style (client specified)
7. Generate mastered version
8. Download result (WAV + MP3)
9. Download loudness metrics/report
10. Share download link + report
11. Mark as delivered

**A/B Mastering Order:**
1. Download mix from client
2. Go to `/studio/mastering`
3. Process 3 times with different settings:
   - Version A: Bright settings (boost highs, clear presence)
   - Version B: Warm settings (boost lows/mids, smooth)
   - Version C: Balanced settings (neutral, professional)
4. Download all 3 versions
5. Create comparison document (before/after)
6. Upload all 3 to shared folder
7. Explain: "Listen to all 3 and tell me which one you prefer"
8. After client votes, deliver their choice + 2 alternates
9. Mark as delivered
