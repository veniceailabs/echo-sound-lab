## How to Execute

### Option 1: Use Existing DemoFactory Component

The `DemoFactory.tsx` component already exists and can generate demos. To use it for all 4:

```typescript

  paperPerfectorDemoHybrid,
  masterLeaseDemoHybrid,
  dataBlasterDemoHybrid,
  echoSoundLabDemoHybrid
];

for (const demo of demos) {
  const result = await HybridDirector.executeDemo(demo, console.log);
}
```

## Technical Details

**Recording Flow:**
1. Browser requests screen capture permission
2. User selects app window
3. MediaRecorder captures at 60fps (VP8 codec)
4. Python backend receives chunks via WebSocket
5. FFmpeg converts to MP4 (H.264/AAC)
6. Final MP4 saved to `~/demos/[app-name]/final_demo_optimized.mp4`

**Voice Generation:**
- Provider: pyttsx3 (Mac Neural TTS - free, high quality)
- Or: ElevenLabs if configured (premium quality)
- Generated in parallel with recording
- Mixed into final video

**Intro Generation:**
- VideoEngine SFS API called via backend
- Generates cinematic 3-5s intro video
- Branded with app name
- Mixed into beginning of final video

**Post-Production:**
- Fade out at end (1-2s)
- Credits displayed (2-3s)
- Final file output to ~/demos/
