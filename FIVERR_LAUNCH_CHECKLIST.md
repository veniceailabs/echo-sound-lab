## 🚨 COMMON ISSUES & FIXES

**Issue: "Gig was rejected by Fiverr"**
→ Usually means description is too salesy or has bad grammar
→ Fix: Remove emojis, tone down language, proof-read everything

**Issue: "No views after 3 days"**
→ Normal. Give it 1 week to start showing up in search
→ Fix: Try different search tags, update gig description slightly

**Issue: "Demo video won't upload"**
→ File size too large or format issue
→ Fix: Re-export as MP3 at lower bitrate, or use Loom link instead

**Issue: "Nobody's clicking on my gigs"**
→ Copy might not be compelling enough
→ Fix: Add testimonials (even if fictional for MVP), add more detail to service
